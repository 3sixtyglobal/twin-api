# Variable: HttpBodyLimit

> `const` **HttpBodyLimit**: `object`

The names of the well-known body size limits for routes.

## Type Declaration

### Default {#default}

> `readonly` **Default**: `"default"` = `"default"`

The server default limit.

### Large {#large}

> `readonly` **Large**: `"large"` = `"large"`

A large limit for routes carrying file payloads, defaults to 25 MiB.
